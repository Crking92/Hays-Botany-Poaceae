# Group B targeted photo-rights hold resolution — source probe

Date: November 12, 2026. Issue #70 owner photo-first priority. **No publication and no photo-ID certification.**

## Why this is needed
The previous Group B source audits found useful photo previews for three of the seven remaining empty-gallery taxa, but secondary pages did not provide exact image metadata. The iNaturalist observation's license is **not** interchangeable with each photograph's license; iNaturalist explicitly documents that distinction (https://inaturalist.freshdesk.com/en/support/solutions/articles/151000169918-can-i-use-the-photos-and-sounds-that-are-posted-on-inaturalist-). The existing web tools could not directly open iNaturalist observation pages or its JSON API in this run. Rather than *invent* approval, this branch proposes a tiny, standalone, **read-only** GitHub Actions Node 22 metadata probe against **five specific existing observation URLs**:

| Species | Exact observation IDs already recorded in Hays candidate manifest |
|---|---|
| Pappophorum bicolor | 136755826 |
| Tridens congestus | 232038649; 135964547 |
| Stapfochloa ciliata (older Chloris ciliata) | 141035831; 23580302 |

For each actual photo, its output prints the photo ID, own `license_code`, `attribution`, original API photo URL, observer, source observation and taxon label to GitHub Actions **logs only**. It uses public HTTP GET calls, no tokens, no photo download, no writes, no modifications to gallery assets, no false rights approvals, and no possibility to publish anything. It labels CC BY/CC0/BY-SA as **rights-possible pending photo ID/image check**; NC photo licenses are conditional on genuinely noncommercial site policies; all others held. The script intentionally does not infer a CC license version or claim that taxon label proves species ID.

### Independent source hazards found during focused web research
- **Stapfochloa ciliata:** Native Plant Society of Texas old Texas Grasses article https://www.npsot.org/posts/texas-grasses/ **credits a photograph by Cleveland Powell as CC BY 4.0**, but the original archived photo URL `https://www.npsot.org/wp/clearlake/files/2022/03/grasses-fringed-windmill-grass.jpg` returned 404. DO NOT copy a placeholder or pretend the original iNaturalist photo ID is resolved. A separate Pl@ntNet entry by **Trap Hers** labels its media **CC-BY-SA** and lists habit and fruit, but its exact media URL/license version could not be extracted; potential follow-on source: https://identify.plantnet.org/da/k-caribbean/species/Stapfochloa%20ciliata%20%28Sw.%29%20P.M.Peterson/data . A USDA Hitchcock-Chase 1950 figure `https://commons.wikimedia.org/wiki/File:Chloris_ciliata_HC-1950.png` is genuinely public domain but is **a drawing, NOT a living-plant photograph**.
- **Tridens congestus:** iNat 232038649, 135964547 provide species-specific photo leads with prior visual review from the original dossier; exact **per-photo** rights/ID are not established. The retailer Eco Blossom https://ecoblossom.com/products/tridens-congestus-pink-fluffgrass features a **garden scene with multiple different clumped grasses**, so neither all visible growth nor rights should be attributed to *T. congestus* automatically. The UT regional description https://w3.biosci.utexas.edu/prc/K12/pdf/Tridens%20congestus confirms a **short contracted panicle**, rather than trusting generic pink wispy garden foliage. Kew POWO has one Herbarium Catalogue image source using a CC BY 3.0 catalogue credit, but the exact image/label/barcode was not isolated for reuse. It should not count as a living reference photo.
- **Pappophorum bicolor:** native-plant seed/nursery photographs and University/NRCS PDFs have distinct third-party creators. For example, USDA's official guide `https://plants.usda.gov/DocumentLibrary/plantguide/pdf/pg_pabi2.pdf` explicitly credits **Forrest Smith / South Texas Natives** for a photo: government PDF publication does not automatically change the separate original image's copyright. A TxDOT guide `https://www.houstontx.gov/police/cpted/planting_information/grass_weed_and_wildflower_guide-TXDOT.pdf` credits **Texas Native Seeds Program** for two field photographs; again **not a documented Creative Commons/photo permission**. The Wikimedia `Pappophorum_bicolor_HC-1950.png` is public-domain **illustration only**, not counted. Indexed photo ID candidates on unreliable mirrored sites are insufficient: name/license/author must come from the original iNaturalist photo record. The standard regional plant guide https://rangeplants.tamu.edu/plant/pink-pappusgrass/ describes the pinkish 5-10 inch panicle and approx. 12 unequal awns per spikelet; search for useful head and habit views.

## Exact acceptance process after workflow logs
1. Parse each `PHOTO` record. Identify the specific **creator, copyright/license and exact original photo**. Use the original `photo_page` and `photo_image_url`; do not substitute observation or species page license.
2. For apparently reusable CC0/BY/BY-SA images, publisher must inspect **actual pixels**, ideally multiple same-observation photos, verify credible species ID (not merely a title), perform original URL/hash dedup, preserve source attribution and exact license version and maintain distinct views.
3. If exact original requests/metadata fail, hold; never infer source approval from the secondary website, garden photo, or collective page CC policy.
4. Existing sole photo/gallery publisher installs eligible photos and verifies **actual public Pages pixels and credits**. Chat 1 integration remains separate from image assets. BONAP county mapping deferred.
