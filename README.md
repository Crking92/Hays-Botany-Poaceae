# Hays Botany — Poaceae (staging)

This is the new, **not-yet-publicly-launched** grass-family repository for the unified Hays County Botany Visual Learner.

**Migration status:** STAGING. The original [Hays County Botany](https://github.com/Crking92/Hays-County-Botany) repository remains the authoritative source and public website until a separately verified cutover.

The first source checkpoint is commit `d5812999ea32d03b873110db1a526e20ac6ea730`, dated 2026-10-28. It inventories **1,402 source files, 112 species, 53 genus records, and 1,012 image files**. Not all source media may legally be carried into a new public site. Rights-held images must be excluded from the public destination and recorded as pending in an exclusion ledger.

No original data should be deleted; this migration requires file-level verification, credit and license checks, annotation review, correct source/cross-family links, and explicit publication readiness.
