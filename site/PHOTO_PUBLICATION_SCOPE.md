# Existing-grass-image release

486 original physical source files are referenced by 604 visual panels for 112 of 112 grass species. Existing CC/CC0 and narrowly credited Bob Harms educational-only photos are distinguished; no blanket third-party reuse. Three original Larry Allain/USGS public-domain JPEGs were copied byte-for-byte from the legacy archive with Git blob hash verification; no new external media were harvested. Remaining source images stay accounted for and are not included in this photo gallery. Human verification of arrows and subtle infraspecific taxa is separate.
