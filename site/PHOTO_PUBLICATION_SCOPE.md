# Existing-grass-image release

443 original physical source files are referenced by 558 visual panels for 105 of 112 grass species. Only strict CC/public-domain and specifically sourced existing files were selected. No new photo file bytes were moved or downloaded; the JPEGs remain in content/taxa/Poaceae. Remaining source images stay accounted for and are not included in this photo gallery. Human verification of arrows and subtle infraspecific taxa is separate.
