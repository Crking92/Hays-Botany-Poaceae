# Canter’s windmillgrass: Gould comparison

> Historical standalone review. Its options and source decisions are integrated in the combined November18 release; current combined counts and verification are recorded in [COMBINED_GOULD_RELEASE.md](COMBINED_GOULD_RELEASE.md). Earlier standalone counts and deployment notes below describe the proposal at that time.

Gould p. 328 names Chloris canterai; the existing Lab profile is Stapfochloa canterae (Paraguayan windmill grass). The illustrated Chloris ciliata and partial C. divaricata treatment on the same page are not used for this profile.

The supplement adds nine precise choices across the existing character groups, covering ligule cilia, branch posture, glumes, fertile lemma and upper sterile florets. The archived page is now confirmed as 328, retaining its original unconfirmed-page status as history. Existing admissions, core traits and media remain unchanged.

Ligule hairs to 7 mm are not membrane height. Fertile awns 2.4–5.5 mm and lowest sterile awns 1.5–3.5 mm remain separately attributed. Gould’s glabrous glumes except a rough midnerve support a narrow ordinary-glume-hair contradiction; this does not imply absence of lemma keel hairs, glands or veins. Historical source differences remain reviewable.

Validation: all 45 core choices and all 157 advanced choices in 24 groups audited. Dedicated tests, Gould reference checks, KR/Johnsongrass/Virginia mapping, three-way key and optional-refinement tests passed. Browser preview: own characters give one supported match (Canter’s); full KR characters give one supported match (KR), with Canter’s excluded for ordinary outer-glume hairs. All 169 candidate profiles remain present.
