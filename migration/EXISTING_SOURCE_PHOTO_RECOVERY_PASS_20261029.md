## Site integration and limitations

The Poaceae site is already available at https://crking92.github.io/Hays-Botany-Poaceae/site/. The hub's default grass search remains on the original working learner until separate owner approval; the dedicated grass site is available as an optional review link. All release counts refer to `site/` published records, **not** all 1,402 original family-source files or all 956 raw photos held directly on Poaceae main. Archive/source photo existence does not imply that a diagnostic anatomy arrow is botanically certified, that a taxon determination is independently voucher-proven, or that every file is legally redistributable.

If current action runs or branches advance, refresh the live release report and update this dated audit rather than using these numbers as permanent constants.
